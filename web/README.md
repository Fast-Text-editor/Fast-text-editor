# Fast Text — web

The browser frontend. It is a thin shell over the same Rust engine that powers
the terminal editor: `fast-text-core` (buffer, undo/redo, search) and
`fast-text-syntax` (highlighting) compiled to WebAssembly via `wasm-bindgen`.

```
web/
├── index.html      # layout
├── style.css       # theme (matches the TUI's dark palette)
├── app.js          # glue: input capture, status bar, toolbar actions
├── pkg/            # generated by wasm-pack (do not edit)
└── smoke.node.js   # runtime smoke test against the Node build
```

## Run it

```sh
./web/serve.sh          # builds wasm, serves on http://localhost:8080
```

or manually:

```sh
wasm-pack build crates/fast-text-wasm --target web --out-dir ../../web/pkg
cd web && python3 -m http.server 8080
```

Then open <http://localhost:8080>. You must serve over HTTP — browsers block
ES-module and WASM loading from `file://`.

## What the page does

- **Edit** on the left (a plain textarea for native caret/IME handling).
- **Live highlight** on the right, rendered by the Rust highlighter.
- **Find / Replace all** run through `fast-text-core` (`findNext`, `replaceAll`).
- **Undo / Redo** call the engine's history.
- **Status bar** shows language, cursor position, and engine line/char counts.
- **Language picker** is populated from the Rust engine (`languageNames()`), so
  the browser exposes the same 340+ languages as the terminal editor.

## Test the engine without a browser

```sh
wasm-pack build crates/fast-text-wasm --target nodejs --out-dir ../../target/wasm-node
node web/smoke.node.js
```
